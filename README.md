# GOLDEN — تانل کرنلی پرسرعت بین سرورها با پنل فارسی (Gold Glassmorphism)

**GOLDEN** یک سیستم تانل کرنلی سروربه‌سرور نوشته‌شده با **Go** برای لینوکس (اوبونتو/دبیان) با **۲۸ پروتکل** (۲۴ پروتکل کرنلی + ۴ تانل اسپوف) و وب‌پنل تمام‌شیشه‌ای طلایی است.

## نصب سریع (تک‌خطی)
```bash
curl -fsSL https://raw.githubusercontent.com/zarem9335-source/TUN/main/install.sh | sudo bash
```

## اجرا با Docker Compose
```bash
docker compose up -d --build
```
